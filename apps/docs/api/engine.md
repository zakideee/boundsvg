# Rust API

Canonical Rust API documentation is published by docs.rs:

- [`boundsvg`](https://docs.rs/boundsvg/latest/boundsvg/) — rendering pipeline, layout orchestration, SVG emission, and raster encoding
- [`boundtext`](https://docs.rs/boundtext/latest/boundtext/) — shaping, line breaking, inline text, vertical text, and intrinsic measurement
- [`boundshape`](https://docs.rs/boundshape/latest/boundshape/) — geometry documents, boolean operations, transforms, and symbol resolution

docs.rs builds each published crate from its registry source, displays the exact crate version, and retains documentation for previous releases. The TypeScript and package APIs remain documented in this site under the other API pages.
